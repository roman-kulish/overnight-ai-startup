# Crypto-Astrology Oracle

## Concept

Merge two belief-driven systems: enter a zodiac sign and a crypto ticker, get a reading that explains the price action using astrology.

## Example

- **Input**: Leo + ETH
- **Output**: "Saturn is transiting your gas fees, creating massive spiritual resistance on the network. Whales are accumulating, but the cosmos are consolidating."

## Data source

CoinGecko free API for real-time crypto prices. Optional planetary ephemeris for realistic natal charts.

## Model

`@cf/meta/llama-3.1-8b-instruct-fp8-fast` with fallback to `@cf/meta/llama-3.2-3b-instruct`.

## Visuals

Mystical star charts layered over stark financial graphs.
